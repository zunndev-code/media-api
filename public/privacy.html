Privacy Policy.

How Ziplan handles your data — last updated August 2026.

1. Information we collect

When you register and use Ziplan, we collect the following information:

  • Account information: name, email address, and password (stored as an encrypted hash).
  • OAuth data: if you register via GitHub, we receive your GitHub ID, username, avatar, and verified public email.
  • Usage data: API request logs including endpoint called, status code, latency, and IP address.
  • Payment data: top-up transaction information (we do not store credit card data directly).

2. How we use your data

Your data is used to provide the service: granting daily credits, enforcing key limits and rate limits, preventing abuse, and showing your usage statistics.

3. API keys

API keys are secrets. Anyone holding a key can spend your credits, so treat them like passwords — never share or publish them.

4. Sharing

We do not sell or rent your data. Transaction data is shared with the payment provider only when you pay. Public stats on this site are aggregated and anonymous.

5. Cookies & local storage

We use an authentication cookie (md_token) so you stay logged in, and local storage for your theme and language preferences.

6. Security

All traffic is served over HTTPS. Passwords are hashed, the database is only reachable by the admin, and API keys are never written into plain-text logs.

7. Your rights

You can request account deletion and a copy of your personal data by contacting us. Deletion removes your keys, usage history, and personal data.

Questions about your data? Email admin@ziplan.eu.cc
