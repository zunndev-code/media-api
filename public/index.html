LANGKAH 1

Daftar gratis

Langsung dapat 1000 credit. Besoknya dapat lagi 1000. Tiap hari, gak putus.

LANGKAH 2

Buat API key

Dari Dashboard, buat key satu klik. Bentuknya md_..., simpen baik-baik.

LANGKAH 3

Kirim request

Tempel key di header X-API-Key. 1 request sukses = 1 credit.

curl -X POST https://zunndev.my.id/api/download \
  -H "Content-Type: application/json" \
  -H "X-API-Key: md_xxx" \
  -d '{"url": "https://youtube.com/watch?v=..."}'
