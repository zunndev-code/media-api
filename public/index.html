API untuk bot kamu

Daftar request dipakai bot kamu: 1 request sukses = 1 credit. Tanpa key tetap bisa, tapi dapat 1000 credit gratis per hari setelah daftar.

POST/api/downloaddeteksi otomatis
GET/api/yt?url=...YouTube
GET/api/ig?url=...Instagram
GET/api/fb?url=...Facebook
GET/api/tt?url=...TikTok
GET/api/x?url=...X / Twitter
GET/api/mp3?url=...audio MP3

Pakai key kamu (kode md_... dari dashboard):

curl -X POST https://zunndev.my.id/api/download \
  -H "Content-Type: application/json" \
  -H "X-API-Key: md_xxx" \
  -d '{"url": "https://youtube.com/watch?v=..."}'

Credit

Pemakaian diukur per hit: 1 request yang berhasil = 1 credit.

Setiap akun baru langsung dapat 1000 credit. Setiap hari, akun yang belum membeli role mendapat tambahan 1000 credit gratis secara otomatis. Credit tidak menumpuk melebihi jatah harianmu.

Harga Role

Role menentukan jatah credit harian kamu. Pembayaran manual (transfer/DANA/QRIS) — info pembayaran segera hadir.
