Cara pakai API.

Dari daftar sampai request pertama, kurang dari 1 menit. Semua layanan pakai cara yang sama.

1. Daftar akun

Buka halaman daftar, isi nama, email, dan password. Akun baru langsung dapat 1000 credit. Setiap hari, akun yang belum membeli role mendapat tambahan 1000 credit gratis.

2. Buat API key

Masuk ke Dashboard, tekan tombol "Buat key". Key berbentuk md_.... Simpan baik-baik — key hanya ditampilkan sekali.

Key dipakai lewat header X-API-Key atau parameter key.

3. Kirim request

Setiap request yang berhasil memotong 1 credit. Kalau credit habis, dapat 402 insufficient_credits — tunggu jatah harian berikutnya.

curl -X POST https://zunndev.my.id/api/download \
  -H "Content-Type: application/json" \
  -H "X-API-Key: md_xxx" \
  -d '{"url": "https://youtube.com/watch?v=..."}'

4. Format response

Sukses:

{
  "status": "success",
  "data": {
    "platform": "Youtube",
    "title": "...",
    "thumbnail": "https://...",
    "duration": 213,
    "uploader": "...",
    "formats": [{ "quality": "1080p", "ext": "mp4", "url": "https://...", "filesize": 11832459 }],
    "audio": [{ "quality": "128 kbps", "ext": "m4a", "url": "https://...", "filesize": 3051204 }]
  }
}

Gagal:

{
  "status": "error",
  "error": { "code": "invalid_request", "message": "Field \"url\" wajib diisi." }
}

5. Kode error

  • 400 invalid_request — parameter salah / domain tidak diizinkan
  • 401 unauthorized — belum login
  • 401 invalid_key — API key tidak dikenal
  • 402 insufficient_credits — credit habis
  • 403 key_disabled — key dinonaktifkan
  • 404 not_found — format tidak ditemukan
  • 409 email_taken — email sudah terdaftar
  • 429 rate_limited — terlalu banyak request (60/menit per IP)
  • 502 scrape_failed — gagal ambil data dari platform

6. Credit & role

1 request sukses = 1 credit. Akun gratis: 1000 credit per hari. Role berbayar menaikkan jatah harian — daftar harga di halaman blog.

7. Tanpa key?

Request tanpa key tetap bisa dipakai (coba-coba / demo), dibatasi 60 request/menit per IP. Untuk pemakaian bot yang serius, daftar dan pakai key kamu — biar credit & statistik tercatat.

Daftar endpoint lengkap ada di halaman Endpoint. Daftar layanan & harga ada di halaman utama.
