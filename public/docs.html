API Guide.

From signup to your first request — under a minute.

1. Sign up

Open the sign-up page, fill in name, email, and password. New accounts get 7,000 free credits every week.

2. Create an API key

Go to the Dashboard and press "Create key". Keys look like md_.... Save it — a key is only shown once.

Keys are used via the X-API-Key header or the key parameter.

3. Send a request

Each successful request costs 1 credit. Out of credits? You get 402 insufficient_credits — wait for the next daily allowance.

curl -X POST https://ziplan.eu.cc/api/download \
  -H "Content-Type: application/json" \
  -H "X-API-Key: md_xxx" \
  -d '{"url": "https://youtube.com/watch?v=..."}'

4. Response format

Success:

{
  "status": "success",
  "data": {
    "platform": "Youtube",
    "title": "...",
    "thumbnail": "https://...",
    "duration": 213,
    "uploader": "...",
    "formats": [{ "quality": "1080p", "ext": "mp4", "url": "https://...", "filesize": 11832459 }],
    "audio": [{ "quality": "128 kbps", "ext": "m4a", "url": "https://...", "filesize": 3051204 }]
  }
}

Error:

{
  "status": "error",
  "error": { "code": "invalid_request", "message": "Field \"url\" wajib diisi." }
}

5. Error codes

  • 400 invalid_request — wrong parameters / domain not allowed
  • 401 missing_key — no API key sent
  • 401 unauthorized — not logged in
  • 401 invalid_key — unknown API key
  • 402 insufficient_credits — out of credits
  • 403 key_disabled — key disabled
  • 404 not_found — format not found
  • 400 registration_failed — email already registered
  • 429 rate_limited — too many requests (60/min per IP)
  • 502 scrape_failed — failed to fetch from the platform

6. Credits & roles

1 successful request = 1 credit. Free accounts: 7,000 credits per week. Paid roles raise your allowance — see pricing on the home page.

7. No key?

Requests without a key still work (trial/demo), limited to 60 requests/minute per IP. For serious bot usage, sign up and use your key — so credits & stats are tracked.

Services & pricing are on the home page. Account, key & stats endpoints are accessed via the dashboard.
